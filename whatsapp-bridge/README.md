# AntiMager WhatsApp Bridge

Bridge lokal untuk memasukkan task AntiMager lewat chat WhatsApp ke diri sendiri.

Setup:
1. Copy .env.example menjadi .env.
2. Isi GROQ_API_KEY.
3. Jalankan npm install.
4. Jalankan npm start.
5. Scan QR WhatsApp jika diminta.
6. Terminal menampilkan URL LAN, misalnya http://192.168.1.5:3000.
7. Di AntiMager buka Pengaturan > WhatsApp Bridge, masukkan URL lalu tekan Simpan & Sinkronkan.

Cara pakai:
+ ada PR B Indo
+ belajar matematika besok jam 7 malam
+ beli karton sebelum Jumat
+ latihan presentasi jam 4 sore
+ bawa buku agama besok

Laptop dan HP harus berada di Wi-Fi yang sama. Windows Firewall mungkin meminta izin Node.js untuk jaringan lokal.
